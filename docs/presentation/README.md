# Презентация «Открытая библиотека»

18 слайдов для защиты проекта, ориентировочно 10–12 минут.

- **[Online-Library.pptx](Online-Library.pptx)** — презентация для PowerPoint или Keynote. Заголовки, подписи и схемы редактируются; скриншоты вставлены как изображения. К каждому слайду добавлены заметки докладчика.
- **[Online-Library.pdf](Online-Library.pdf)** — готовый вариант для просмотра и показа; страницы экспортированы как изображения, поэтому код удобнее копировать из репозитория.
- **[SPEAKER_NOTES.md](SPEAKER_NOTES.md)** — текст пояснений ко всем слайдам.
- **[Presentation-Pack.zip](Presentation-Pack.zip)** — PPTX, PDF и заметки одним архивом.
- **[overview.jpg](overview.jpg)** — обзор всех слайдов.
- `assets/` — скриншоты сайта, фрагментов кода и вывода тестов.

На GitHub откройте нужный файл и нажмите **Download raw file**. Для PPTX также можно выбрать **View raw**. На macOS распакуйте архив двойным щелчком и откройте PPTX в PowerPoint или Keynote. Если программы нет, используйте PDF в «Просмотре».

Скриншоты сделаны с работающего приложения. Фрагменты кода взяты из реальных файлов, имена файлов и номера строк указаны на изображениях. 16 тестов повторно выполнены успешно. Автоматические проверки проводились в облачной Linux-среде, не на физическом Mac.

Перед защитой добавьте своё имя и группу на титульный слайд, запустите сайт и подготовьте PNG/JPEG для демонстрации добавления книги. В заметках отмечены ограничения проекта, чтобы не заявлять нереализованные функции.
