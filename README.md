# Открытая библиотека

Учебный Django-проект по заданию «TSIS I». Интерфейс на русском языке; два приложения: `books` и `users`. База — SQLite, внешние сервисы и ключи не требуются.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

`seed_demo` создаёт 10 книг и оригинальные декоративные PNG-обложки через Pillow; повторный запуск не дублирует книги. Демоаккаунтов и паролей нет: зарегистрируйтесь на сайте. При необходимости администрирования создайте пользователя:

```bash
python manage.py createsuperuser
```

Вход в панель: `/admin/`. Книги можно добавлять как через сайт после входа, так и через панель администратора.

## Возможности и соответствие заданию

| Требование | Реализация |
| --- | --- |
| Django, два приложения, маршруты | `config/`, `books/`, `users/`, отдельные `urls.py` |
| Общая шапка и подвал, наследование | `templates/base.html`, дочерние шаблоны с `extends` |
| HTML5, CSS, адаптивность, анимация | семантическая разметка; `static/css/style.css`, `@media`, `@keyframes`; поддержка уменьшения движения |
| JavaScript | проверка размера/типа обложки и предпросмотр в форме добавления |
| Статика | `{% load static %}`, локальные CSS/JS без CDN |
| Обложки через ImageField и `/media/` | `Book.cover`, `MEDIA_ROOT`, `MEDIA_URL`, multipart-форма; изображения JPEG/PNG/WebP до 5 МБ |
| Циклы и условия | `for` для книг/жанров/полей, `if` для обложек, пагинации и авторизации |
| Список и страница книги | `/books/`, `/books/<id>/` |
| Имя вошедшего пользователя в шапке | `{{ user.username }}` в `base.html` |

Дополнительно: регистрация, вход, выход через POST с CSRF; создание книг только авторизованными пользователями; серверная валидация; поиск по автору и названию; жанры и пагинация по 8 книг; сообщения об успехе; состояния пустого каталога и отсутствующей обложки; административная панель.

Это каталог описаний книг: скачивание полных текстов заданием не предусмотрено. Поиск использует стандартный Django `icontains`; у SQLite регистронезависимость гарантируется для ASCII, для кириллицы нужно соблюдать регистр. Для полной поддержки Unicode в большой библиотеке рекомендуется PostgreSQL.

## Проверка

```bash
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
```

Тесты используют отдельную временную базу и временные каталоги обложек. Проверяют страницы, поиск/фильтры/пагинацию, 404, регистрацию/вход/выход, запрет анонимного добавления, CSRF, экранирование HTML, создание книги с реальным изображением и ошибки загрузки. Проверяется повторяемость `seed_demo`.

## Структура

```text
config/                   настройки Django, корневые маршруты, ASGI/WSGI
books/                    модель, формы, представления, миграция, тесты
  management/commands/    команда seed_demo
users/                    регистрация, маршруты авторизации, тесты
templates/                общий шаблон, страницы, фрагменты
static/css/               стили и адаптивность
static/js/                проверка и предпросмотр обложки
.vscode/                  интерпретатор, отладчик, расширения
manage.py
requirements.txt
```

## Локальные данные и настройки

`.venv/`, `db.sqlite3`, `media/`, `staticfiles/` исключены из Git. При переносе проекта установите зависимости, выполните миграции и `seed_demo`; свои загруженные обложки и базу переносите отдельно. Не удаляйте базу или `media/`, если нужны внесённые данные.

По умолчанию включён локальный режим разработки. Переменные процесса: `DJANGO_SECRET_KEY`, `DJANGO_DEBUG` (`1`/`0`), `DJANGO_ALLOWED_HOSTS` (список через запятую). `.env` автоматически не читается. Для публичного сервера нужны отдельные настройки: случайный секрет, `DEBUG=0`, корректные хосты, HTTPS, production WSGI/ASGI-сервер, раздача статики после `collectstatic` и безопасная раздача пользовательских медиа. `runserver` и локальный ключ предназначены для разработки.
