# Результаты проверки

Проверено в облачной Linux-среде: Python 3.12.14, Django 5.2.18, Pillow 12.3.0, Chromium. На физическом Mac проверки не выполнялись; проект использует переносимые команды Python, а инструкция и настройки VS Code подготовлены для macOS.

- `python manage.py check` — ошибок нет.
- `python manage.py makemigrations --check --dry-run` — незаписанных изменений моделей нет.
- `python manage.py test` — 16 тестов успешно.
- `python -m pip check` — конфликты зависимостей отсутствуют.
- `seed_demo` запущен дважды: 10 книг, повторно 0 новых, обложки корректны.
- HTTP-запросы к главной, CSS и обложке вернули 200.
- В Chromium пройден реальный сценарий: поиск по автору и жанру, страница книги, регистрация, имя в шапке, добавление книги с PNG, отображение сохранённой обложки, выход.
- JavaScript: некорректный файл отклоняется, для PNG появляется предпросмотр; ошибок JavaScript в сценарии нет.
- Проверены ширины 320, 390, 768 и 1440 px: горизонтальной прокрутки главной нет.

Скриншоты: `docs/desktop.png`, `docs/mobile.png`.
